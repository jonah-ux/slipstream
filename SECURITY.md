# Security policy

Slipstream is a local index library and CLI. It does not contact a provider,
read credentials, or execute indexed content. The public demo uses synthetic
vectors and metadata.

Please do not include secrets, private source, personal data, or customer data
in an issue. For a report that could expose users, email the maintainer through
the contact method on the GitHub profile before opening a public issue.

Supported versions:

| Version | Support |
| --- | --- |
| `0.1.x` | security fixes and responsible reports |
